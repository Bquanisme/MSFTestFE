Centered Tabs and Pills

To center/justify the tabs and pills, use the .nav-justified class.

@for (tab of centerTab; track tab.id) { }
@if ( getActiveTab( centerTab, activeCenteredTab() ); as activeTab ) {

}

Toggleable / Dynamic Tabs

To make the tabs toggleable, add the data-bs-toggle="tab" attribute to each link. Then add a .tab-pane class with a unique ID for every tab and wrap them inside a <div> element with class .tab-content. If you want the tabs to fade in and out when clicking on them, add the .fade class to .tab-pane:

@for (tab of dynamicTab; track tab.id) { }
@if ( getActiveTab( dynamicTab, activeDynamicTab() ); as activeTab ) {

{{ activeTab.title }}

{{ activeTab.content }}

}
